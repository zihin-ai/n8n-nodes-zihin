# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 1.x     | Yes |
| < 1.0   | Security fixes only until 2027-01-31 — please upgrade |

## Reporting a vulnerability

Please **do not** open public issues for security problems. Email **support@zihin.ai** with the affected version, steps to reproduce and the impact. Never include API keys or customer data.

We acknowledge within 2 business days and share an initial assessment within 5 business days.
